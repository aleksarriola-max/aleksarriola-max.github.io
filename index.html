Lifeline — from orbit to heartbeat

Lifeline is a human-in-the-loop triage and dispatch system for post-earthquake search and rescue, engineered end-to-end in a single day and placed first among 40 competing teams. It fuses Copernicus EMS structural damage grading with Maxar pre/post-event satellite imagery into a probabilistic survivor-likelihood score for every collapsed structure in the affected area, continuously re-weighted as new life-sign telemetry comes in. A constrained vehicle-routing layer built on Google OR-Tools converts that ranking into optimized multi-team dispatch plans, which a human commander reviews and authorizes over a live Telegram command channel.

The entire reasoning stack runs as local inference on a single Dell Pro Max workstation — no external API calls, no cloud dependency — and is engineered to communicate its own epistemic limits: every ranking is surfaced as a decision aid rather than a verdict, and the system is explicit about which inputs are live sensor data versus simulated for the demo.
